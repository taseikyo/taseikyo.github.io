Tich·十月总结/2018

Posted on 2018-10-30 In Blog

这个月听了个学术论坛，然后去杭州参加了 cncc 2018，想着是总结就都列进去了。
下面是 2018 年十月的总结。

1. 看的非专业书籍

姑且完成了每个月两本书的小目标。。。

  1. 『蔡澜潮晒日本』 - 蔡澜
    主要就是蔡澜在日本的各种逛吃逛吃: )，看了一部分就看不下去了。

  2. 『正说大明十六帝』- 刘亚玲
    和之前看的『正说大宋十八帝』是同一个作者，讲述了大明十六位帝王的政治生涯。

2. 看的专业书籍

  • 《Electron in Action》(pdf)
    这本书是介绍 Electron，从入门到入土 ：)

  • 《Python Graph》(pdf)
    这本书是介绍如何用 Python 进行画图，主要是使用 matplotlib 库。

  • 《Creating Google Chrome Extensions》(pdf)
    这本书是介绍如何创建 Chrome 扩展的，但是我看了一章就不想看了，感觉写得好烂。。。可能是我太菜了吧。。。

  • 《Xen 虚拟化技术完全导读》
    介绍 Xen 的，看了将近一个月还没看完第一章，断断续续。。。

3. 讲座&会议

  • 2018 年中南地区计算机学科研究生学术论坛

    • 论坛主题：区块链——开启数字经济的新引擎
    • 主办单位：华中科技大学计算机科学与技术学院
    • 承办单位：WeBank 微众银行
    • 时间：2018 年 10 月 17 日
    • 地点：武汉光谷凯悦酒店
    • 内容：
      • 涂子沛——通往数据 2.0 时代
      • 黄永峰——区块链与云计算融合机制下的大数据安全保护模型及应用
      • 贾瑶琪——分片技术–区块链即将到来的扩容良方
      • 张开翔——区块链技术在金融领域的应用实践

  • 2018 中国计算机大会

    • 会议主题：大数据推动数字经济（Big Data Drives the Digital Economy）
    • 主办单位：中国计算机学会（CCF）
    • 承办单位：萧山区人民政府、浙江大学
    • 时间：2018 年 10 月 25 - 27 日
    • 地点：杭州国际博览中心
    • 3 场大会主题论坛，50 场前沿技术论坛、20 场特色活动及 100 个科技成果展
    • 三场主题论坛
      • CPU 及 xPU 芯片未来之路
      • 软件工程 50 周年了，路在何方？
      • 共享经济未来走向

4. 看的论文

  1. Alto: Lightweight VMs using Virtualization-aware Managed Runtimes
    主要内容是为数据中心提出了一个新的虚拟化技术 (Alto)，它在管理运行时层 (the managed runtime layer) 进行虚拟化，主要目标是提供小、安全、强隔离性的虚拟机。

  2. An Application-Specific Memory Management Unit for FPGA-SoCs
    主要内容是提出了在 FPGA 上附加一个 MMU 的概念以及如何在设计中实际使用它

  3. MirageOS Unikernel with Network Acceleration for IoT
    主要内容是为 MirageOS 增加了一个网络性能加速器，提高了健壮性和网络性能

  4. UniGuard: Protecting Unikernels using Intel SGX
    主要内容是在 unikernel 中 集成 Intel SGX 以保护云环境中的安全敏感计算 (security-sensitive computations)

5. 写的几行代码

  1. project-euler
    刷了一些欧拉计划的题。

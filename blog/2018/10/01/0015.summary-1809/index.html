Tich·九月总结/2018

Posted on 2018-10-01 In Blog

为了避免浑浑噩噩虚度光阴，另一方面也越来越健忘，所以决定每个月写个总结叭。
主要内容也就是对上个月的工作简单做个回顾总结。
下面是 2018 年九月的总结。

1. 看的非专业书籍

『正说大宋十八帝』- 刘亚玲
（本来打算是看两本的，结果另一本没看完）
书的内容如书名那般，讲述了南北宋的十八位帝王的一生。
本人是非常喜欢历史的，特别是宋朝的历史（然而没勇气去读《宋史》），因为感觉宋朝风气比较开放，统治者对文人（士大夫）比较宽容，经济发达（然而军事…），人民生活也相对来说比较丰富，出现了交子、瓦肆这些东西，在哪看到说好像汴京城没有宵禁，不知道是不是真的。
看完这本书真是令人叹息赵匡胤，他一手打下天下，但是他的后继者没几个是合格的，一步步断送了大好河山。有人说“北宋缺将，南宋缺相”，然而事实真是如此吗？不见得吧。

2. 看的专业书籍

  • 《Learn Python 3 the Hard Way》(pdf)
    这本书中文译名好像是《笨方法学 Python3》感觉挺基础的，反正我是很快就翻完了（有些也直接略过了），看上面讲的例子基本都是一些基础知识，应该是给刚入门的人看的吧，对我不是很有用。

  • 《Cpp Application Development with Code Blocks》(pdf)
    这本书讲的是如何用 Code Clocks 开发 C++ 应用程序，页数不多，感觉还是有点用的吧，包括如何编译生成 DLL 库、如何开发 Win32 应用，最后讲了一个开发图片查看器的例子，虽然我现在用 Qt 比较多233。

  • 《Python for Data Analysis》(pdf)
    介绍如何使用 Python 进行数据分析，还没看完。

  • 《Xen 虚拟化技术完全解读》
    介绍 Xen 虚拟化技术的，还没看完。

  • 《Real World OCaml》
    OCaml 从入门到入土，还没看完。

3. 看的论文

很惭愧，这个月就读了一篇 paper，《A survey of memory management techniques in virtualized systems》不过内容很充实，毕竟是个 survey，调查了虚拟化系统中使用的各种内存管理技术，是一篇值得一读的 paper，问题是太长了看到后面就忘了前面:joy:

4. 写的几行代码

这个月主要写了四个主要的东西吧（包括开始但未完成）

  1. 弹幕转换器
    主要功能是用于将其他平台的视频弹幕转换成 bilibili 格式的弹幕，以配合 BiliLocal 来观看本地视频。
    已经实现了腾讯、优酷的弹幕转化
    下载的话，腾讯已经做好了，测试了几个，不知道是否有 bug；优酷针对的是电影，对于要会员的似乎没问题了，但是普通的就有问题。

  2. autoQA
    主要功能是自动提交 QA。

  3. d3 可视化框架
    可视化数据，以弧形圆环的方式呈现，代码有 error，但是对效果似乎没有影响。
    已经出了一个 视频

  4. leetcode
    刷了一些 leetcode 题。

  5. project-euler
    刷了一些欧拉计划的题。
    这个欧拉计划还是那个 计科艺研小组 的一个大佬推荐给我的。

以上。

九月的总结大概就是这些，下个月要继续加油才是。

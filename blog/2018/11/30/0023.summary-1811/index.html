Tich·十一月总结/2018

Posted on 2018-11-30 In Essay

不知不觉又摸鱼一个月了:3
下面是 2018 年十一月的总结。

1. 看的非专业书籍

  1. 『阿 Q 正传』 - 鲁迅
    记得之前初高中的时候看过一遍了，然后那天 (11/3) 早上去图书馆找书的时候正好看到了，索性就再借来看一遍。

  2. 『我们仨』 - 杨绛
    久仰大名，在结束的时候看到旁边睡着一本『我们仨』于是果断借来了。
    最后还是没看完，看了一部分看不下去了;3

2. 看的专业书籍

  • 《Python Graph》(pdf)
    这本书是介绍如何用 Python 进行画图，主要是使用 matplotlib 库。没看完，感觉还是用的时候直接查相应的函数比较靠谱吧。

  • 《chrome扩展及应用开发》(pdf)
    这本书的内容就是书名，介绍如何开发 chrome 扩展与应用。

  • 《chrome扩展及应用开发》
    除了看这本书的电子版，之前去图书馆借书正好查到有这本书于是就借过来了。

3. 看的论文

  1. Efficient Shared Memory Orchestration Towards Demand Driven Memory Slicing
    主要内容是提出了一个轻量级的动态和需求驱动的内存分片方法 MemLego，由三部分组成：

    1. MemExpand 在存在不断变化的工作负载时提供弹性共享内存分配和回收。
    2. MemSwap 提供共享内存分页功能，可显着提高内存交换效率，加快 VM 执行的吞吐量恢复速度。
    3. MemPipe 提供共享内存管道，用于共存 VM 之间的高性能通信。

  2. Unikernels as Processes
    主要内容是提出将 unikernel 作为进程运行，改善了对 VM 的隔离，同时对内核函数的访问权限减少一半；另外由于作为进程运行，所以继承了许多特定于进程的特性如高内存密度，性能，启动时间等。

  3. Unikernel Monitors Extending Minimalism Outside of the Box
    主要内容是对云出了一个新的执行单元，通过捆绑 unikernel 和专用的监视器 (monitor) 构建，这样的专用监视器小而简单，并且功能强大，足以运行真正的 unikernel。

4. 写的几行代码

  1. leetcode
    刷了一些 leetcode 题。

  2. txt2img
    分享文字为图片，将之前的代码稍微整理了一下。

  3. Slacking-Visualization
    摸鱼时间可视化，还有很多地方需要改进。【已删除】

  4. 牛客网
    在牛客网刷了一些题

十一月的总结大概就是这些，下个月要继续加油才是。

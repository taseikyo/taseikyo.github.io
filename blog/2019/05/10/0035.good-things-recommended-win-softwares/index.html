好物推荐之 windows 软件

Posted on 2019-05-10 In Essay

记录一下在 windows 上用过的软件，都是用过之后感觉比同类型好或者用的太久习惯了。
目的是为了以后换了电脑/笔记本还能将这些老朋友装上，不至于因为健忘（？）而将这些曾用过的“好软”忘掉。
本来不想分先后，但是太乱了; 于是最后用 Py 根据软件名排了个序。

2345 看图王(绿色版)

为什么要加个绿色版，因为其实这个看图王真的很好用，但是广告很恶心。
我之前是用美图看看来着，其实也不错，但是好久没更新，有种年久失修的感觉，UI 很丑。

Adobe 全家桶

这个就不多介绍了 hhh

Bandizip

一款免费精简的压缩/解压软件，从知乎上知道的，最开始是 2345 好压。后来有广告就打算换一个，在知乎上看到这个。
它还有一个很棒的小功能，就是右键菜单下的 “新建文件夹”，习惯之后真的不想去点二级目录下的新建文件夹。

Clover

clover 是资源管理器的一个扩展，增加了类似 Chrome 多标签页的功能，不用每个目录单独开一个窗口。
最开始知道这个软件是在 计算机艺术研究小组 那个群，群主上传了一个破解版的 clover，我下载来试试水，康康是个啥玩意，结果一下子就爱上了，不用多个窗口 alt + tab 来切换，直接点击 tab 页即可，可以说方便不少，日常必备。

Cmder

一款超好用的 Windows 下的终端，如果你受够了 cmd 和 power shell，那么 cmder 就是你的不二之选。

Dism++

其他网站上的介绍 “Dism++ 是一个强大同时轻量易用的小工具，集系统清理、优化、启动项管理、驱动管理等许多常用 Windows 设置与一身”，其实我就用来清垃圾 233。

FinalShell

从知乎上知道的，据说是一款 “替代 Xshell 的良心国产软件 FinalShell”，不说其他的， UI 确实更好看。

Listary

在知乎上知道的，本来自己就是一个强迫症，喜欢一个啥都没有的桌面，有个这个之后更是加剧了我的这一点，因为可以双击 ctrl 弹出搜索框。
它搜索速度很快，很快就能将你要用的软件找到，同时还可以自定义快捷键，很棒的一款软件。

Mendeley

同学推荐的论文管理软件，同时还可以直接用来看论文，但是我用得不多，因为我一般都是直接下下来看。

Mp3tag

用来给音频加信息/封面的一款软件。

OBS

免费录屏/直播推流软件，当然我是用来录屏的，最开始是用的 Bandicam，后来转 OBS 了。

Pandownload

一个第三方百度云下载软件，可以不限速，不过现在好像不行了，只能下前两/三个，之后就限速了，不过比官方的还是好多了。

Potplayer

一款很棒的多媒体播放器，甚至可以用它来看电视 233，太知名就不多赘述了。

ScreenToGif

一款很棒的 gif 录制工具，我已经把之前用过的那款忘了 2333。

Snipaste

一款多功能的截图软件，我主要用来采集屏幕颜色 233

Sublime Text 3

其实我在纠结到底要不要加这个，因为我用了四年了，从大一知道这个就一直再用，每次重装系统都会装这个。
后来出的 Atom 以及现在用的人很多的 VS Code 我都用过，只能说习惯真的是很可怕的东西。

坚果云

一款超棒的自动同步网盘，我是在大三的时候从知乎上知道的，还推荐给管机房的老师（小虎哥），在一次重装系统之后，机房上都装上了坚果云，我觉得他们应该给我广告费 233。

天若 OCR 文字识别

识别率还挺高的一款 ORC 识别软件，在老殁那看到的。

小丸工具箱

作为一名 UP🐖 必备的视频压制软件。

火绒

一款国产的免费高效的杀毒软件，从知乎上知道的，近来名气越来越大，确实感觉不错。

福昕 PDF 阅读器

很棒的一款 PDF 阅读器，用了很久了，想了想最初的那款 PDF 阅读器，是啥来着？

WeChat Pay

Alipay

win10 terminal 初体验&美化

Posted on 2019-07-09 In Study

从 win10 terminal 的消息出来就想试试了，然而系统版本过低导致无法使用一直很气，上周将自己笔记本重装了，得到的版本是 1503 😂 然后升级了好久仍然只是到了 1809 (win+r => winver)，最后下了 win10 易升强行升到 1903，赶紧从应用商店下了 terminal 来试试。

第一眼其实不咋滴，感觉就是将 cmd 和 powershell 合并了，但是我好歹折腾这么久不能干看着啊，还是上手体验了一波。

还是有些地方很不习惯，比如 复制，在 cmder 中是 ctrl+shift+c，在 terminal 中是右键选中文字
再如 清除当前命令行，cmder 中是 ctrl+u，在 terminal 中是 esc；为此我还特意去提了个 issue 233

根据那个回复我开始了美化之旅。

但是改了以后看不太清命令了，将字颜色改为纯白色，还是不太行。玩了一会还是把背景相关设置注释掉了 :D

之后安装了 oh-my-posh，大概是 oh-my-zsh for Power Shell，主要步骤如下：

  1. 安装 posh-git
  1. 安装 oh-my-posh
  1. 导入 oh-my-posh

如果提示导入出错，改用管理员权限打开 terminal

  1. 安装字体与设置主题

当你导入 oh-my-posh 之后，可能会有乱码，所以需要换字体，推荐 Microsoft YaHei Mono，它是微软雅黑和 Consolas 的混搭。

输入 theme 命令会列出所有主题，可以使用 Set-Theme theme 来修改主题。

  1. 修改配置文件

仅上面的步骤确实是生效了，但是当你下次重启 terminal 的时候，又得重新导入模块，所以需要修改配置文件。
